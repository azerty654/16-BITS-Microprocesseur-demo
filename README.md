# 16-BITS Microprocesseur
Un mini-microprocesseur 16 bits que j’ai conçu moi-même sous Logisim, avec une UAL complète, plusieurs registres et une unité de contrôle programmable (UC). Ce projet a surtout pour but de comprendre concrètement l'architecture d'un microprocesseur, comment ses différentes parties communiquent entre elles et comment un assembleur fait pour décomposer les instructions en code machine qui pilotera les différents composants du système.
